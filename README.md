# Bot do Discord para Controle do Aternos

Este bot permite controlar o seu servidor do Aternos diretamente pelo chat do Discord utilizando comandos simples.

## Funcionalidades
- `!ligar`: Inicia o servidor do Aternos.
- `!desligar`: Desliga o servidor do Aternos.
- `!status`: Mostra informações detalhadas sobre o servidor (status, software, versão, jogadores online).

## Instalação e Execução

1. Clone o repositório:
   ```bash
   git clone https://github.com/skibidieoak-dev/aternos.git
   cd aternos
   ```

2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Configure o arquivo `.env` com suas credenciais baseando-se no `.env.example`.

4. Execute o bot:
   ```bash
   python3 bot.py
   ```
